## 桌面版

- MyGo Native 对齐 WebView 的悬浮、选中、卡片展开和设置布局，改善剪贴板列表重排时的稳定性。
- 改善快速粘贴、下拉菜单、右键子菜单和悬浮说明的可读性。悬浮预览自动调整高度，靠近屏幕边缘时调整打开方向。
- 修复分享入口，并扩充 Emoji 和符号的中文搜索。改善窄窗的更新通道选项排版。
- 优化 Windows 11 的 Mica 和 Acrylic 材质。原 macOS 主题更名为「平白」（FlatWhite），并与液态玻璃、科幻一起对齐双端设置卡片的间距。
- Windows 的两套 NSIS 安装器采用 DezirClip 的新视觉样式。

## 下载与更新

- Windows x64 和 ARM64 各提供 WebView（Tauri）与 MyGo Native 安装器。
- Linux x64 和 ARM64 的两套桌面版均提供 AppImage、DEB 和 RPM。
- 已安装用户可以在设置中切换到 **Preview（预览版）**，继续接收对应桌面版和架构的自动更新。
