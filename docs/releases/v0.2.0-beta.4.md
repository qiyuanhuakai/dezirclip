# DezirClip v0.2.0-beta.4

本次预览在 Windows 和 Linux X11 上同时提供 Tauri 与 MyGo Native。两个桌面共用 Rust 核心和数据格式。

- MyGo 主窗口默认使用原生渲染，并支持六套内置主题。历史搜索、预览、标签、置顶排序和设置可在原生窗口中使用。
- 合并 MyGo 历史读取和搜索请求，减少与后台服务之间的往返。
- 修复 X11 全屏截图只捕获左上区域、区域截图坐标越界，以及主窗口无法跟随鼠标唤出的问题。
- 进入设置时，「隐私设置」默认折叠，每次重新进入都可按需展开。

| 平台 | 架构 | 桌面下载格式 |
| --- | --- | --- |
| Windows | x64、ARM64 | NSIS 安装包 |
| Linux X11 | x64、ARM64 | AppImage、deb、rpm |

文件名含 `MyGo` 的桌面包使用 MyGo Native。两个桌面沿各自的预览更新路径升级。Windows NSIS 和可写的 AppImage 支持确认后安装签名更新。deb 和 rpm 使用原有包管理方式更新。旧版 MyGo 用户可先手动覆盖安装一次。
