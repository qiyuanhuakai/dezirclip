# DezirClip v0.2.0-beta.3

本次预览继续提供 Tauri 桌面版和 Windows x64 MyGo 桌面版。两者共用 Rust 核心、本地协议和数据格式。

- 修复 MyGo 事件连接失效后历史列表无法继续更新的问题，并增加主窗口启动及重连诊断。
- 修复 MyGo 隐私状态读取失败后无法恢复的问题，改善隐私状态重新读取前的界面反馈。
- 将隐私选项集中到独立的设置页面，整理设置导航、帮助提示和更新区域。
- 修复 MyGo 文字预览宽度、窗口尺寸和视频固定预览问题，并调整设置窗口布局。
- 悬浮预览在显示前完成尺寸计算，避免窗口首次缩放时固定按钮从指针下移开。

Windows x64 MyGo 用户可下载 `DezirClip-v0.2.0-beta.3-windows-x64-MyGo-setup.exe` 手动更新。安装前请退出应用。MyGo 需要 Microsoft Edge WebView2 Runtime，安装包没有 Windows Authenticode 签名。Tauri 通过现有签名更新流程获取预览更新。
