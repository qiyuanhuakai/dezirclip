# DezirClip v0.2.0-alpha.8

- 恢复完整卡片滚动。快速滚动时仍能看到置顶状态、正文和已加载的图片。新进入视口的缩略图按需加载。
- 连续缩放时保持当前页面可见，停下约 220 毫秒后按最终尺寸重新排版。
- 修复配置多组主快捷键后无法设置隐私会话快捷键的问题。每组组合键分别检查冲突。X11 上长按录制的主键，会等到实际松键后再注册。
- 悬浮窗和固定窗可显示带行内样式及样式表的富文本，保留字号、字重、颜色、列表和表格。遇到无法显示的外部资源时，仍显示同一条记录中的其他格式和内容。多个 CSS 选择器共享声明，超出预览预算的样式会被跳过。
- 主窗口吸附在屏幕边缘时，可以移入悬浮预览并点击图钉。预览窗上的点击纳入应用窗口判定。
- 悬浮和固定图片预览都支持在没有滚动条的方向上平移。放大后，超出窗口的方向仍可拖动浏览。
- 打开右键菜单时会停止悬停预览，关闭菜单后恢复正常触发。
