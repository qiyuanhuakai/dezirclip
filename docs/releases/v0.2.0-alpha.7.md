# DezirClip v0.2.0-alpha.7

本版面向预览通道，重点改进主窗唤起、长列表滚动和窗口缩放。

- 主窗恢复复用 Host 返回的隐私状态、服务实例和版本。历史读取完成后，键盘操作可以直接使用该查询结果。设置页和表情页跳过历史查询。
- 切到其他应用会遮回已揭示的正文。普通搜索和标签草稿可以继续使用。隐藏窗口、会话到期和切换 Host 仍会使旧结果失效。
- 置顶卡片和普通记录共用虚拟列表。快速滚动时先显示轻量摘要，减速后恢复完整卡片。离开视口的缩略图会退出等候队列，每个窗口最多并行读取两个预览。
- 快捷粘贴和截图窗在首次使用时创建。截图窗停放时缩回小尺寸。Windows 隐藏窗口时也会通知 WebView2 停止呈现，重新唤起主窗时先恢复保存的尺寸和主题。
- 收藏图片按需读取最多 256 像素的预览。大型背景的显示副本限制为长边 3840、短边 2160 像素。超限动画图的显示副本取静态帧，发送收藏时仍使用原文件。

MyGo 仍是独立实验组件。
