# DezirClip v0.2.0-alpha.3

第三个 v0.2 预览版集中修复 alpha.2 使用中发现的界面、标签和截图问题。

- 修复点击顶部栏、失焦或打开预览后主窗口进入空白状态的问题；关闭“方向键选择”时，Esc 仍可关闭窗口。
- 恢复背景图片的保存和显示，处理快速切换图片、保存失败及过期响应覆盖新设置的情况。
- 标签搜索使用正确的标签范围；受保护记录支持主动查看、隐藏和管理，普通记录的编辑、复制与文本转换按需读取完整正文，并继续校验 Host 和隐私授权。
- 隐私会话等设置统一使用 DezirClip 的下拉栏、快捷键录制、开关和折叠控件，调整横屏与窄屏布局。修复空格快捷键、Agent Skill 路径显示和导入主题的默认字体继承。
- 区域截图以显示选区前冻结的同一帧作为底图和裁剪来源，避免把遮罩及虚线框写入图片；按实际显示尺寸映射像素，并兼容高缩放下的窗口取整。

保留 alpha.2 的本地 Host/Service、隐私会话、实验性 Wayland 支持和“关于”设置。数据库仍为 schema 24；升级前请保留备份，旧版程序不得写入升级后的数据库。

本次发布包括 Windows 与 Linux 的 x86_64、ARM64 安装包及独立 CLI。Windows NSIS 和可写 AppImage 支持签名原位更新；deb、rpm、Flatpak 使用原有包管理方式更新。Stable 与 Preview 保持独立。

源码修复已通过对应提交的 AI 复审、303 项前端测试和隔离浏览器检查。多屏原生截图、Windows 合成器时序及 Linux 快速重开仍有实机验证边界；Wayland 继续作为实验功能提供。最终发行包身份、签名与安装升级结果以本版本发布验收记录为准，见 [alpha.3 发布验收](../specs/v0.2-alpha3-release.md)。
