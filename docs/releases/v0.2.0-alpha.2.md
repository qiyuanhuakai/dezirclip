# DezirClip v0.2.0-alpha.2

第二个 v0.2 预览版推进至 Phase 5：增加可选的本地 Host/Service、隐私会话与反馈规则、实验性原生 Wayland 支持，并在设置中新增“关于”。

- 默认桌面继续使用内嵌 Core。可选 Service 通过受同用户身份和会话约束的本地通道提供服务，桌面与 Service 交接时排空正在进行的捕获工作，确认原监听进程退出后再接管。协议客户端按 Host 实例和隐私版本校验请求，断线后重新取得快照。
- 隐私会话支持手动结束和定时结束。开启后暂停自动记录；界面隐藏、切换隐私状态或更换 Host 时撤销已经展示的敏感正文。手动保存必须单独确认，确认只允许当前保存，不恢复自动记录。
- 敏感文本、HTML、图片及文件附件使用受保护的存储和读取流程。普通摘要不含敏感正文、OCR 或附件路径；图片预览限于内存，受保护文件的临时导出会随授权失效而撤销。备份包含敏感数据时要求加密口令。
- 隐私反馈分别提供“仅此条不敏感”“精确内容例外”“忽略来源”“保护来源”。精确例外绑定完整内容和来源，撤销后重新保护仍受其关联的记录；来源规则不自动解除既有记录的保护。规则管理和判定说明不返回正文。
- 原生 Wayland 优先使用 ext-data-control，兼容可用的 wlr-data-control，并明确报告当前协议和能力。提供文本、HTML、图片和文件的复制与监听；不支持的自动粘贴、快捷键、窗口跟踪和权限能力会在界面中停用或说明。Portal 接口存在不代表已取得权限。
- 设置新增“关于”，集中展示真实构建版本、来源提交、目标平台、协议、数据库结构和实际链接组件，以及检查、下载和安装更新。Stable 与 Preview 继续分开，自动检查默认关闭，更新包仍须通过签名验证。

数据库升级到 schema 24。升级前请保留备份；旧版程序不得写入升级后的数据库。Linux 密钥库不可用时，敏感写入明确失败。Windows 安装更新与可写 AppImage 更新保留历史；发行版包仍通过对应的软件包管理方式更新。

Wayland 仍属实验功能。不同合成器提供的协议和权限不同，实际可用范围以能力报告为准。此版不包含 MyGo 客户端、Phase 6–8 的独立界面实验，也没有云同步或远程服务。

验证范围与凭据见 [alpha.2 发布验收](../specs/v0.2-alpha2-release.md)。
