## DezirClip v0.2.0-rc4

- **MyGo Native 窗口唤出**。短时间内再次打开窗口时复用少量已加载的普通图片缩略图。历史或隐私状态变化后重新加载，唤出时也减少了重复读取设置的开销。
- **X11 窗口拖动**。按下主窗口标题栏后，窗口管理器立即接管移动。拖动期间减少贴边检测的窗口查询。
- **Windows 窗口拖动**。使用系统四向移动指针，拖动结束后恢复。窗口隐藏时使用低内存优先级，准备唤出时恢复正常优先级。
- **标签与表情**。大量标签时只绘制可见范围。表情和符号的索引加载及模糊搜索在后台完成。透明度为零时暂停 GIF 背景刷新。

Windows x64 和 ARM64 提供 NSIS 安装包。Linux x64 和 ARM64 提供 AppImage、deb 和 rpm。Tauri 和 MyGo Native 均可从 Preview 通道更新。ZIP 和 tar.gz 是独立的 `dzc` 命令行工具。
