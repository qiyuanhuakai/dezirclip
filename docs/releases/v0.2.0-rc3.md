## DezirClip v0.2.0-rc3

- **环形快速粘贴**。在「设置 → 工具」切换列表或双环布局。双环直接浮在桌面上，内环选择内容类型，外环点击条目粘贴。靠近左右边缘或顶部时呼出半环。全环和半环可分别设置外圈扇区数。
- **浮窗材质**。快速粘贴和悬浮、固定预览复用云母、亚克力、液态玻璃和平白主题的背景与边框。Windows 列表快贴和预览支持系统材质。
- **MyGo 隐藏窗口**。手动隐藏后暂停贴边轮询，常驻进程改为等待设置变化。隐藏后释放闲置缓存并回收工作集，按内存压力安排后台垃圾回收。重新打开窗口时恢复常规回收策略。
- **组件库**。WebView 和 MyGo Native 使用 [Deziro UI v0.4.1](https://github.com/qiyuanhuakai/deziro-ui/releases/tag/v0.4.1)。

Windows x64 和 ARM64 提供 NSIS 安装包。Linux x64 和 ARM64 提供 AppImage、deb 和 rpm。两个桌面版本均可从 Preview 通道更新。ZIP 和 tar.gz 是独立的 `dzc` 命令行工具。
