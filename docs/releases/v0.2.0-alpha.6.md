# DezirClip v0.2.0-alpha.6

本次更新集中修复设置、预览与 Windows 粘贴体验。

- 统一设置项字体和 DezirClip 控件，将“方向键切换时预览”移到“方向键选择”下方。
- 隐私会话改用开关，移除持续时间选择；快捷键复用单快捷键的录入、自动保存和清除方式，精简规则说明。
- 为富文本新增独立的默认打开程序设置；“关于”页移除重复版本号，将版本信息放入默认折叠的构建详情。
- 修复标签管理和表情包页面右侧大面积留白。
- 修复文本与图片混排内容的预览，改善富文本及长图显示。
- 修正预览在极端宽度下的位置跳动、部分主题透明度不生效和透明度滑条错位；压缩固定预览工具栏，点击 pin 按钮即可关闭，图片支持拖拽与滚轮缩放。
- 加强 Windows 粘贴目标校验，目标变化或粘贴失败时保留队列和记录，避免旧粘贴收尾隐藏新唤出的快速粘贴窗口。
- NSIS 安装遇到关键文件无法写入时中止并报告失败，避免静默跳过后误报成功；中止不代表自动回滚。
- 加强 Windows 文件剪贴板解析，拒绝无效或不完整的文件列表，限制内存读取范围。
- 未检测到 MyGo 实验组件或检查失败时，禁止新选 MyGo，Tauri 仍可选；保留已有偏好，组件缺失时说明回退到 Tauri。

## 实验状态与已知问题

本次安装包不包含 MyGo 辅助程序，快速粘贴默认继续使用 Tauri。MyGo 仍是源码实验，Phase6 尚未通过，Phase7 未启动；本版本不将其列为随包功能或性能提升。[性能与验收边界](../specs/phase6-performance.md)

实验性测试仍有 Windows 主进程在清理前发生堆损坏的记录，根因尚未定位。本次修复不代表该历史问题已经关闭。

## 自动更新

这是预览版本。安装包通过签名、最终身份和升级门禁后公开发布，并按更新后的发行策略同步至 Preview 自动更新通道。Stable 不接收本预发布版本。已公开的 alpha.6 使用原始成功发行记录补同步，不重建或替换安装包；通道同步不代表 MyGo Phase6 或额外性能验收已通过。
