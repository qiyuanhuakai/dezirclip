## MyGo Native 界面与交互

- 对齐剪贴板卡片的字体、预览高度与悬浮操作，恢复简洁模式下的置顶，并让各粘贴入口遵循同一套历史排序设置。
- 改善标签页导航、批量操作和表情面板的连续滚动。文字处理与隐私使用两级右键菜单，支持键盘操作。
- 对齐窄窗口下的设置布局、快捷键录制、字体与默认应用选择。修整备份导入、导出及覆盖确认的主题样式，并让 Liquid Glass 保留弹窗下方的文字和轮廓。
- 改善关闭设置后 MyGo Native 更新的进度恢复。Linux AppImage 等新版窗口打开后再清理旧包。

## 下载与更新

- Windows x64 和 ARM64 提供 Tauri 与 MyGo Native 的安装程序。
- Linux x64 和 ARM64 的两种桌面版本均提供 AppImage、DEB 和 RPM。
- Preview 通道按已安装的桌面版本提供对应更新。独立 `dzc` CLI 另有下载。
