# DezirClip v0.2.0-alpha.9

- 新增独立 Windows x64 MyGo 测试版，与现有 Tauri 版共用 Rust 核心、本地协议和数据格式。MyGo 安装包包含独立桌面入口、CLI、后台 Service 和配套指南；安装到当前用户目录，创建开始菜单与桌面快捷方式，并提供卸载入口。alpha.9 的安装包复用已发布 ZIP 中的原始二进制，作为补充附件发布。
- MyGo 主窗口使用 WebView 加载共享 React 界面和 CSS 主题；快速粘贴、截图、悬浮及固定预览使用 MyGo Native。关闭主窗口后，原生常驻端继续处理快捷键，按需重建主 WebView。
- 接入历史搜索、分类、标签、置顶、编辑、富文本及图片粘贴、表情、OCR、截图、备份导入导出、主题和设置；隐私检查与数据修改通过共享 Rust Host 执行。
- 接入主窗口、搜索、顺序粘贴和富文本粘贴快捷键，包括鼠标中键；原生快捷键不依赖主 WebView 存活。
- 接入 Windows 系统剪贴板设置、Win+V 调整、Explorer 重启及管理员重启。提权交接保留原数据目录配置，普通安装提权后仍可迁移数据目录。
- 修复慢 Host 读取与空闲销毁之间的唤回竞态，以及 Explorer 重启阻塞 Win+V 事务保活的问题。确认失败后不再执行成功路径的延迟重绑。
- 更新 Mio 至 1.2.4，纳入上游针对 Windows 命名管道 I/O 提交后失败时的释放后使用修复。
- Windows 剪贴板读取使用同线程窗口身份和作用域锁，文本读取在锁内完成 Unicode 解码与句柄释放。
- 修复取消快捷键录制后仍提交延迟结果、快捷键别名及修饰键顺序导致重复注册的问题。
- 富文本快捷粘贴排除自身主窗口，避免自粘贴后删除历史。设置重置遇到私密导出撤销失败时，会在后续请求中继续完成队列清理和原生界面刷新。

MyGo 测试版使用手动下载更新。原生 Wayland 的全局焦点和输入能力仍受平台限制。测试版不代表已经证明所有设备上的内存或性能收益。

Windows 安装包为 `DezirClip-v0.2.0-alpha.9-windows-x64-MyGo-setup.exe`。需已安装 Microsoft Edge WebView2 Runtime。安装、覆盖升级或卸载前，请退出 MyGo 托盘及后台 Service；文件被占用时安装程序会拒绝继续。卸载保留与 Tauri 版共享的历史、设置及系统设置所有权记录，不重置系统剪贴板或 Win+V。MyGo 安装包未做 Windows Authenticode 签名，仍使用手动更新。

历史压力运行中曾出现 Service 堆损坏检测、resident 启动退出、验收观察器进程权限拒绝，以及剪贴板内容正确但目标编辑器未收到粘贴的偶发现象。这些现象尚未全部形成根因闭环；后续通过样本和新增诊断不代表已证明根除。建议先用于测试，并保留现有数据备份。

实现、审查及验证边界见 [PR #174](https://github.com/qiyuanhuakai/dezirclip/pull/174) 和 [PR #175](https://github.com/qiyuanhuakai/dezirclip/pull/175)。
