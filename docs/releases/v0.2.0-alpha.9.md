# DezirClip v0.2.0-alpha.9

- 新增独立 Windows x64 MyGo 测试版，与现有 Tauri 版共用 Rust 核心、本地协议和数据格式。MyGo 压缩包包含独立桌面入口、CLI、后台 Service 和配套指南。
- MyGo 主窗口使用 WebView 加载共享 React 界面和 CSS 主题；快速粘贴、截图、悬浮及固定预览使用 MyGo Native。关闭主窗口后，原生常驻端继续处理快捷键，按需重建主 WebView。
- 接入历史搜索、分类、标签、置顶、编辑、富文本及图片粘贴、表情、OCR、截图、备份导入导出、主题和设置；隐私检查与数据修改通过共享 Rust Host 执行。
- 接入主窗口、搜索、顺序粘贴和富文本粘贴快捷键，包括鼠标中键；原生快捷键不依赖主 WebView 存活。
- 接入 Windows 系统剪贴板设置、Win+V 调整、Explorer 重启及管理员重启。提权交接保留原数据目录配置，普通安装提权后仍可迁移数据目录。
- 修复慢 Host 读取与空闲销毁之间的唤回竞态，以及 Explorer 重启阻塞 Win+V 事务保活的问题。确认失败后不再执行成功路径的延迟重绑。
- 更新 Mio 至 1.2.4，纳入上游针对 Windows 命名管道 I/O 提交后失败时的释放后使用修复。

MyGo 测试版使用手动下载更新。原生 Wayland 的全局焦点和输入能力仍受平台限制。测试版不代表已经证明所有设备上的内存或性能收益。
