## DezirClip v0.2.0-rc2

- **隐藏后的内存回收**。Windows Tauri 主窗口隐藏后请求挂起 WebView2，重新打开时先恢复页面。MyGo Native 在窗口全部隐藏或关闭后执行一次工作集回收。
- **浮窗视频播放器**。固定视频预览提供播放、暂停、进度拖动、时间、静音、音量和循环，配有独立的播放画面和图标工具栏。
- **标签页**。打开单条删除确认或删除条目时，保留当前标签页其余条目的「全部显示」状态。
- **浮窗主题**。云母、亚克力、液态玻璃和平白的浮窗与快速粘贴面板采用各自的材质、边框和圆角。
- **组件库**。React 和 Go 桌面组件均依赖独立发布的 [Deziro UI v0.3.2](https://github.com/qiyuanhuakai/deziro-ui/releases/tag/v0.3.2)。

Windows x64 和 ARM64 提供 NSIS 安装包。Linux x64 和 ARM64 提供 AppImage、deb 和 rpm。两个桌面版本均可从 Preview 通道更新。ZIP 和 tar.gz 是独立的 `dzc` 命令行工具。
