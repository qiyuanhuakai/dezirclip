# DezirClip v0.2.0-beta.2

继续并行提供 Tauri 和 MyGo 桌面版，共用 Rust 核心、本地协议和数据格式。MyGo Windows x64 下载项为 `DezirClip-v0.2.0-beta.2-windows-x64-MyGo-setup.exe` 安装包；Tauri 保留 Windows x64/ARM64、Linux x64/ARM64 发行包。

- 修复 Windows MyGo 从托盘唤醒、拖动并固定窗口后，点击条目无法粘贴到原目标的问题。保留经过进程身份校验的最近外部窗口；任务栏、托盘和本应用窗口不会覆盖目标。
- 修复 MyGo 前端快捷键和粘贴完成后立即销毁 WebView 的遗漏路径；改为先隐藏，再按已启用的空闲销毁设置释放。
- 修复 MyGo 无法保存“粘贴后移到顶部”，以及设置刷新时清空背景、重新开启搜索框/方向键选择、关闭顺序粘贴或取消固定不同步的问题。
- 对齐快速粘贴行为：鼠标与 Enter 提交均保留历史，不受主窗口“粘贴后删除”设置影响。修复 Tauri 切换粘贴音效误改删除状态的问题。
- 多文件仍保留为一条历史记录，按紧凑/普通模式行数限制展示；优先利用现有空间，最后一行延展，单个视频文件名使用整行，放不下的部分才省略。
- 主卡片只请求有限尺寸图片缩略图，视频首帧只在悬浮预览中解码。多图片复用图片卡片的高度限制和圆角，补齐文件类型、来源和子组件图标回退。
- 滚动时取消正在加载的悬浮预览，停止滚动后再显示；键盘选择导致自动滚动时也会恢复当前选中项预览。
- 修复 MyGo 标题栏双击最大化、非焦点状态下悬浮预览缺失、文件拖回自身及重复拖入的问题。
- 修复 Windows OCR 异步对象生命周期引发的一类 Service 原生崩溃；保留退出码和异常日志，便于追踪其他退出原因。

MyGo 继续手动下载安装包更新，需要 Microsoft Edge WebView2 Runtime，安装器包含桌面入口、CLI、Service、快捷方式和卸载入口。安装、升级或卸载前退出应用；卸载保留共享历史和设置。MyGo 安装包没有 Windows Authenticode 签名；Tauri 继续使用既有签名更新流程。

beta.2 为预发布版本。跨平台验收使用隔离的 Windows/X11 桌面；Linux Mint/Cinnamon 原设备仍需复测，不将代码路径对齐等同于所有桌面环境已逐项人工验证。若 Service 再次退出，请保留数据目录中的退出日志及发生时间。
