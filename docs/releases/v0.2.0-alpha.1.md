# DezirClip v0.2.0-alpha.1

v0.2 的首个预览版，集中完成敏感写入保护、应用内更新与 Core 分离。

- 敏感内容加密失败会明确报错；正文、预览、HTML、OCR 和敏感标签在同一事务中完成保护。暂不支持完整加密的敏感图片与附件会被拒绝保存。
- 新增应用内更新设置，支持 Stable / Preview、手动检查、下载进度与安装确认。自动检查默认关闭；更新包必须通过内置公钥的签名验证。
- Windows 更新保留安装位置、历史和应用持有的系统设置；真正卸载只恢复仍属于应用的修改。可写 AppImage 支持原位更新，其他 Linux 包继续通过各自的安装方式更新。
- 提取 dzc-core、dzc-platform 与 dzc-protocol，捕获业务独立于 Tauri。GUI 继续直接使用 Core，独立 dzc、TUI、只读 MCP 与 Quick Paste 保持可用，不新增常驻服务。
- 捕获通知只广播记录 ID，并按需读取界面摘要；平台能力报告明确区分可用与不支持。独立 Linux CLI 保留 glibc 2.28 分发基线。
- 增加组件构建信息和受限历史摘要接口，为未来跨前端客户端准备版本与数据边界；现有界面继续使用 Tauri，默认不启动额外进程。

旧版首次在 Windows 手动迁移时，请选择安装器的保留现有安装选项，或运行 `setup.exe /P /UPDATE`。已经安装的旧卸载程序无法被新 hook 修改，选择先卸载仍会运行旧清理逻辑。此版本内置的 updater 会使用更新参数。

数据库迁移至 schema 19，保留现有历史；旧程序会拒绝写入新结构。升级前的备份请保留。Linux 密钥库不可用时，敏感写入会失败，不会退回明文保存。

本版 Linux 桌面范围为 X11。可选服务与 IPC、隐私模式 2.0、原生 Wayland 实验后端分别列入后续 alpha.2、alpha.3、alpha.4。

后续 MyGo Quick Paste 将作为可关闭的独立实验，先验证协议、隐私、焦点与整套应用的性能；本版不包含 MyGo 客户端。原生截图界面和整体 Host 迁移仍是条件性后续方向。

验证结果与平台边界见 [发布验收](../specs/v0.2-alpha1-release.md) 和 [性能记录](../specs/v0.2-performance-validation.md)。
