## DezirClip v0.2.0-rc1

- MyGo Native 升级到 MyGo v0.10.0，按需创建截图与快速粘贴窗口。关闭闲置销毁时，主窗口隐藏并稳定闲置后只回收一次工作集，保留原进程以便唤醒。
- 固定预览窗可播放本机剪贴板记录中的单个视频文件。Tauri 和 MyGo Native 使用各平台可用的媒体解码器。
- X11 修复 MyGo 主窗口圆角和区域截图冻结图覆盖任务栏的问题。
- 删除单条标签记录时保留当前标签的显示状态。调整云母、亚克力的选中高亮，并为云母、亚克力、平白、液态玻璃和复古提供各自的浮窗样式。

Windows x64 和 ARM64 提供 NSIS 安装包。Linux x64 和 ARM64 提供 AppImage、deb 和 rpm。两个桌面版本均可从 Preview 通道更新。ZIP 和 tar.gz 格式的 `dzc` 是独立命令行工具。
