# DezirClip v0.2.0-alpha.10

继续并行提供 Tauri 桌面版和独立 Windows x64 MyGo 桌面版，共用 Rust 核心、本地协议和数据格式。MyGo 下载项为 `DezirClip-v0.2.0-alpha.10-windows-x64-MyGo-setup.exe`；Tauri 保留 Windows x64/ARM64 和 Linux x64/ARM64 发行包。

- 原生快速粘贴取消“加载更多”按钮，滚动接近底部时自动加载下一页。保留每页 50 条、最多 1000 条的边界；键盘滚动同样触发预加载。搜索、隐藏、隐私状态变化和粘贴操作会使过期的加载请求失效。鼠标悬浮选择，单击提交，Enter 粘贴。
- MyGo 普通隐藏时保留已经加载的自定义背景，唤醒时校验背景设置，不再重复传输整张图片；背景就绪后再显示窗口。空闲销毁 WebView 后仍会释放背景，重建时重新加载。托盘左键和右键首项统一为显示／隐藏。
- 修复 MyGo 唤醒时等待事件长轮询、并发图片预览偶发失败、删除条目导致列表闪动，以及全局隐私显示未覆盖后续加载条目的问题。
- 修复自动 OCR 的触发与结果回读、手动 OCR 保存、富文本通过外部编辑器打开，以及服务中断后的窗口恢复。退出应用时关闭所拥有的 Desktop、WebView 和 Service 进程；显式唤醒可恢复已退出的 Service。
- 完善 MyGo 任务栏隐藏、程序与安装快捷方式图标、贴边收纳与唤出位置、后台内存模式，以及快速粘贴和悬浮预览的主题、透明度、图钉、提示与交互。截图补充鼠标形态和选择框动效。
- dzc 不带参数时进入 TUI；帮助界面提供彩色分类和详细命令说明。日常 PR/master CI 与完整发布验收分开，发布继续保留平台、协议、隐私和安装升级检查。

在同一 Windows CI runner 上，2.69 MB 合成背景的普通隐藏唤醒没有重新读取整图，原生激活至显示为 104–109 ms，无背景为 89–103 ms。带背景的销毁重建约 2.2 秒，背景读取与传输约 0.83 秒。这不是与 Tauri 的配对基准，也不代表所有设备都达到相同延迟。

MyGo 仍使用手动下载安装包更新，需 Microsoft Edge WebView2 Runtime。安装包包含独立桌面入口、CLI 和 Service，提供桌面／开始菜单快捷方式与卸载入口。安装、升级或卸载前退出应用；文件占用时安装器拒绝继续。卸载保留共享历史和设置。MyGo 安装包不提供 Windows Authenticode 签名；Tauri 的更新制品继续使用既有签名更新流程。
