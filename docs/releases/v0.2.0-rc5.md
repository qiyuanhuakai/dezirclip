## DezirClip v0.2.0-rc5

- **WebView 表情与符号**。字符表从本地资源按需加载，缩小了面板的 JavaScript 文件。中英文模糊搜索继续使用同一份字符表。
- **桌面构建**。随包的 `dzc` 和 `dzc-service` 在同一次 Cargo 构建中共享依赖编译。独立 CLI 仍使用专用兼容构建。
- **构建维护**。清理发布构建和开发 CI 中的 Rust 编译警告，并在生产 WebView 验收中覆盖字符表加载和符号搜索。

Windows x64 和 ARM64 提供 NSIS 安装包。Linux x64 和 ARM64 提供 AppImage、deb 和 rpm。Tauri 和 MyGo Native 均可从 Preview 通道更新。
