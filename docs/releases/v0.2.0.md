## DezirClip 0.2.0

- **两种桌面版本**。Tauri 使用系统 WebView，MyGo Native 使用 Go 绘制界面。两个版本与 `dzc` 命令行工具共享本地剪贴板历史。MyGo Native 改善了 Windows 和 Linux X11 的窗口拖动，并减少了反复唤出时重复加载图片缩略图的开销。
- **快速粘贴**。在「设置 → 工具」切换列表或双环。双环内圈选类型，外圈点选内容。靠近左、右或顶部边缘时可使用半环，全环和半环可分别设置外圈扇区数。
- **搜索、标签和预览**。表情和符号支持中英文模糊搜索。标签页支持在管理模式中查看经授权的受保护内容，并在滚动时自动加载更多。固定预览可播放本地视频，格式取决于系统解码器。
- **界面与主题**。内置云母、亚克力、平白（FlatWhite）、液态玻璃、科幻和复古六套主题。快速粘贴和预览浮窗随主题调整材质、边框和圆角。

### 下载和更新

Windows x64 和 ARM64 提供 NSIS 安装包。Linux x64 和 ARM64 提供 AppImage、deb 和 rpm。文件名含 `MyGo` 的桌面包为 MyGo Native。ZIP 和 tar.gz 为独立的 `dzc` 命令行工具。

Windows NSIS 和 Linux AppImage 支持通过 Stable 通道获取签名更新。Preview 用户也可升级到 0.2.0。deb 和 rpm 用户可下载相同格式的新包。尚无内置更新功能的旧版可下载安装包手动升级。
