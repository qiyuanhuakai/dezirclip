# DezirClip v0.2.0-beta.1

继续并行提供 Tauri 桌面版和独立 Windows x64 MyGo 桌面版，共用 Rust 核心、本地协议和数据格式。MyGo 下载项为 `DezirClip-v0.2.0-beta.1-windows-x64-MyGo-setup.exe`；Tauri 保留 Windows x64/ARM64 和 Linux x64/ARM64 发行包。

- 修复 MyGo 贴边唤出后离开收纳区域、无法再次隐藏的问题。贴边悬停唤出显示完整窗口并保留边缘位置；普通唤出仍保留防误收纳间距。
- 修复主快捷键和中键隐藏主窗口时立即销毁 WebView 的问题。现在保留渲染进程，按已配置的空闲销毁策略释放；关闭按钮的行为保持原样。
- MyGo 原生快速粘贴面板跟随鼠标位置唤出，靠近屏幕底部时向上展开，并限制在鼠标所在屏幕的工作区内；每次唤出重新定位。
- 修复 Win+V 接管顺序：先经确认让 Windows 释放快捷键，再注册并提交设置；取消或失败时恢复设置。`Super+V` 与 `Win+V` 表示同一个 Windows 修饰键，同时修复别名比较与异步回滚使用旧快捷键列表的问题。
- 增加 Service 退出诊断：数据目录中的 `service-lifecycle.log` 记录启动、退出、传输错误及 Rust panic 源码位置；Windows MyGo 的 `desktop-service-exit.log` 由常驻进程记录观察到的内核退出码。日志会轮转，不记录剪贴板正文、请求参数或 panic payload。补充本地管道断连防护。
- 恢复拖动调整窗口大小时的实时内容重排。Windows 和 Linux 支持将图片/文件拖入窗口保存，以及将包含文件或图片的卡片拖至外部窗口附加文件。
- 修复 X11 截图的屏幕色深、行跨度处理和显示服务识别，覆盖区域/全屏按钮与快捷键路径。

Service 偶发退出的现场根因仍在排查，beta.1 不将其标记为已彻底修复。若再次发生，请保留上述退出日志及发生时间；正常退出记录、内核退出码和 Windows 错误事件需结合判断。Linux Mint/Cinnamon 的原现场截图问题仍需设备复测。

MyGo 继续使用手动下载安装包更新，需要 Microsoft Edge WebView2 Runtime。安装包包含桌面入口、CLI 和 Service，并提供桌面／开始菜单快捷方式与卸载入口。安装、升级或卸载前退出应用；文件占用时安装器拒绝继续，卸载保留共享历史和设置。MyGo 安装包不提供 Windows Authenticode 签名；Tauri 更新制品继续使用既有签名更新流程。beta.1 为预发布版本。
