# beta.2 MyGo / Tauri 行为对照

本轮检查共享前端命令、两端窗口生命周期与原生 Host 路由；不要求两套渲染器内部实现相同。

| 行为 | 结果与修复 | 验证入口 |
|---|---|---|
| 托盘显示/隐藏、拖动并固定后粘贴 | MyGo 补齐外部前台窗口跟踪，排除任务栏和本应用，校验目标进程身份 | Windows TrayPaste：左键、右键菜单、固定窗口重新激活 |
| 快捷键/粘贴完成隐藏与空闲释放 | MyGo 前端桥改用 HideMain，避免直接 Close | Windows/X11 主卡片粘贴：先隐藏、保持窗口存活、配置期限后退出 |
| 设置持久化与双向同步 | 补齐 move_to_top_after_paste 协议/Go/Tauri 路由；清空背景、搜索框、方向键、顺序粘贴、固定状态支持反向更新 | Core 设置往返/过期拒绝，Go Library，双模式前端构建 |
| 快速粘贴历史保留 | MyGo 跟随 Tauri 快速面板，独立于主窗口删除设置 | Windows 在 delete_after_paste=true 时反复鼠标/Enter 粘贴同一记录 |
| 粘贴音效 | 移除 Tauri 音效设置误写 delete_after_paste 的分支 | Tauri 编译及设置分派代码检查 |
| 附件排版与预览取消 | 两版共享行数预算/最后一行扩展与滚动取消；修复键盘自动滚动恢复 | 纯布局测试、隔离浏览器实际组件和事件验收 |
| 连续截图 | MyGo 截图开始被明确 Busy 拒绝时有限重试；传输失败、隐私变化和完成提交不重放 | Go 边界测试及 X11 连续按钮/快捷键截图 |
| OCR、隐私、文件打开、截图、拖入/拖出 | 复核共享 Core/Host 路由，保持授权/目标校验；本轮沿用已修复路径 | 既有 Windows/X11 原生验收及协议隐私门禁 |
| 背景唤醒、贴边、快捷键与退出 | 保留已实现的背景就绪后显示、贴边防误收纳、快捷键事务和退出日志 | 既有 WakeTiming、MainHotkeys、native lifecycle 验收 |

保留的产品差异：MyGo 主窗口使用 WebView，快速粘贴、截图及预览使用原生绘制；Tauri 使用对应 WebView 或已支持的可选原生面板。MyGo 发布 Windows x64 安装器并手动更新，Tauri 使用既有签名更新渠道。Linux MyGo 原生验收不意味着此版本新增 Linux MyGo 发行入口。

测试结果以 PR #193 和 beta.2 发布工作流的实际状态为准。此清单记录检查范围，不声明全部平台行为已穷尽验证。
