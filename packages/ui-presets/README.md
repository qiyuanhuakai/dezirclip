# Deziro UI Web-derived presets

This GPL-3.0 module contains the six theme catalogs sampled from the React
WebView CSS. Applications can use `presets.Select("macos", "light").Kit()`
with the independent MIT MyGo Native component library.

FlatWhite (`macos`), Liquid Glass, and Sci-Fi are original designs by qiyuanhuakai. Retro,
Mica, and Acrylic build on upstream styles. The generated catalogs also
include shared Web controls.
