# Experimental Quick Paste Surface

This module uses MyGo **v0.6.4**, commit
`6255ea40139d06e0762a7c4a32626148ba410478`, and Go **1.27.3**.
It creates one initially hidden native Panel and reuses it across activations.
It does not register shortcuts, read a database, capture a clipboard, expose a
network service, or install an updater.

The Desktop owns the child and speaks the private BE4 / 64 KiB protocol in
`docs/specs/phase6-surface-control.md`. The helper uses the generated DTOs and
the existing authenticated local Go IPC client. Only a `history_read` Surface
grant is accepted. Rows are bounded metadata; selecting one sends its ID and
the original state back to the Desktop. Paste and target restoration remain
parent responsibilities.
An uncertain paste is never retried automatically. On the next explicit user
activation, a parent `paste_unavailable` notice gets its own visible banner;
query results cannot erase it, and hiding clears it with the display session.

Native text input and IME come from MyGo. Queries wait 300 ms after committed
input, and typing invalidates the previous selection immediately. Every query
has a sequence and session/display/Host/epoch/revision ticket. Pagination
appends only contiguous, unique rows from the same state. Hide cancels query
work, closes the event connection and clears summaries. A resync, Host change,
or privacy epoch change clears the view and reports failure to the parent.

Theme tokens are generated by `pnpm run surface:tokens`; do not edit
`theme/tokens_generated.go`. Opacity affects the panel background, leaving
controls readable. The parent supplies physical geometry and scale, which are
converted to MyGo DIPs. Actual cross-monitor placement still requires native
validation; model tests are not compositor or IME evidence.

Build with the repository's `pnpm run surface:build` entry. It supplies the
version, source, state, build ID and Rust target triple through `-ldflags`.
The builder verifies the original module, makes a build-owned copy and removes
only MyGo's automatic updater-cleanup call. The exact patch ID is
`mygo-v0.6.4-no-startup-cleanup-v1`; the module cache and committed `go.mod`
stay unchanged. A temporary modfile selects that verified copy. The helper
requires that patch ID at runtime and reports it as `toolkit_patch_id`.
`--build-info` prints this Go helper's own identity and fixed MyGo identity;
it does not claim to link Rust Core. Normal UI execution requires
`source_state=verified_checkout`, the fixed toolkit patch and an exactly
matching parent/Host build. An ordinary unpatched `go build` cannot start UI.

Pure model and build identity checks:

```
go test ./internal/...
```

No native UI is started by those packages. Run functional tests only in the
disposable Windows runner or the reviewed private X11 fixture. A successful
compile or synthetic protocol fixture does not establish native focus,
real paste, DPI, IME, multi-monitor support, or a performance improvement.
